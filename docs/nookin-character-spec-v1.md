# Nookin 角色制作规范 v1

状态：已根据 `assets/pet.png` 完成造型提取，并生成四视图和中性正面参考。侧面与背面属于生成式设计推断，尚未成为正式模型。原始素材保持不变。

## 目标

制作一个用于 Unity 桌面伴侣的 3D 角色。外观以 `assets/pet.png` 为主参考。角色需要能抬手、坐下、眨眼，后续能被拖动、摸头并坐在其他应用窗口边缘。

## 正面必须保留的特征

| 部位 | 可见特征 | 建模要求 |
|---|---|---|
| 整体 | 大头、短四肢、圆润的玩偶比例 | 轮廓优先于写实解剖；站立时重心稳定 |
| 面部 | 圆脸、暖肤色、黑色卷发、棕色大眼、小鼻与带牙齿的笑嘴 | 建立双眼睁开的中性基础脸；眨眼与笑嘴做成表情 |
| 帽子 | 浅奶黄色动物帽，两只软耳、额前白色牙齿、帽顶黑色小眼 | 帽耳可独立弯曲；牙齿与脸之间避免穿插 |
| 衣服 | 蓝色宽松连体衣，袖口与裤脚收紧 | 肩部和胯部留出抬手、坐下的变形余量 |
| 披肩 | 暖橙色短披肩，胸前圆纽扣和系绳 | 与上臂之间留空间，避免挥手时大面积穿模 |
| 口袋 | 腹部一侧橙色小口袋，缝线明显 | 保持明显轮廓，但无需全部缝线做成立体几何 |
| 鞋袜 | 奶白色鞋面、较深鞋底 | 鞋底需有清晰接地面，供站立锚点使用 |
| 材质 | 柔和、细腻，接近玩偶插画 | 哑光为主；保留暖色脸颊与轻微布料纹理 |

## 姿态规范

`pet.png` 的眨眼与比手势用于动作、表情参考，不烘焙进基础网格。基础角色为双眼睁开、双手自然打开的 A-pose，手臂与身体留出绑定空间；不以现有 GLB 的姿态或拓扑限定新模型。

第一批动作：安静待机、单手挥手、坐下。第一批表情：中性睁眼、眨眼、微笑。动作需保留帽耳的细微跟随，并可从站立过渡到坐下。

## 侧面与背面设计约束

原图没有直接给出这些角度，下列内容是设计推断，制作三视图后需检查整体是否仍像正面的 Nookin。

- 侧面：头部仍占主体，脸颊和帽檐略向前；帽耳从头顶自然垂下，不呈硬角；腹部鼓起但坐姿能压缩。
- 背面：黄色帽子包覆后脑，黑发少量从帽沿露出；橙色披肩覆盖肩背但不拖到膝盖；蓝色连体衣背部保持简洁。
- 两侧：披肩围绕肩膀连续连接；两只鞋的体量一致；口袋只放在参考图所示一侧。
- 不自行加入尾巴、背包、翅膀、文字、徽标或另一套服装。

## 对三视图的要求

输出一张四视图设计板：正面、左侧、右侧、背面；每个视角同尺度、同站姿、头顶与鞋底对齐、白色或透明背景、均匀光照。正面必须严格遵循 `pet.png`，其余视角补全结构。另保留一张单独的双眼睁开 A-pose 正面图，便于图生 3D 与后续绑定。

检查顺序：先看轮廓，再看帽耳、脸、披肩、口袋和鞋，最后看颜色。任何生成结果如改变帽子形状、服装颜色或加入新部件，都应舍弃或局部修正。

## 3D 交付要求

- 可编辑的建模源文件，包含网格、骨骼、材质、纹理与动作。
- 用于 Unity 的 FBX 或 GLB 文件；保留清晰的骨骼与材质命名。
- 独立表情与至少待机、挥手、坐下三个动作片段。
- 正面、侧面、背面渲染图，与本规范逐项比对。
- 不覆盖 `assets/pet.png` 或其他原始素材。
